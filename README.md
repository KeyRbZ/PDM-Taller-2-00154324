## Descripción del Proyecto
FoodSpot es una aplicación móvil desarrollada en **Kotlin** y **Jetpack Compose** para la exploración y descubrimiento de restaurantes. Este proyecto ha sido diseñado siguiendo los lineamientos del Taller 2 de la materia PDM, enfocándose en la implementación de arquitecturas modernas y gestión de estado reactiva.
